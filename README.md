# 熊本市 車中泊避難者支援システム (Kumamoto Car Shelter Support System)

熊本地震における災害関連死（約80%）の抑制を背景に、車中泊避難者の把握困難や健康悪化（エコノミークラス症候群・深部静脈血栓症等）を解決するための防災支援SPA Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 車中泊避難者向け機能（アプリインストール不要・ブラウザ完結）
- **URL / QRコードから即時アクセス**: スマートフォン等のブラウザで即座に避難者登録が可能。
- **直感的な避難者登録フォーム**:
  - 避難場所（アクアドームくまもと / 熊本競輪場 各150台）
  - 駐車区画番号の選択（空き区画の自動選定・手動選択）
  - 代表者氏名・年代・電話番号（受付証の再表示や安否確認キー）
  - 車両情報（車種・ナンバー・色・ボディタイプ）
  - 同乗者情報（全員分の氏名・年代・続柄）
  - 体調状態・症状チェック（エコノミークラス症候群警戒：足のむくみ、ふくらはぎの痛み、呼吸苦など）
  - 特記事項（乳幼児、妊産婦、後期高齢者、基礎疾患、ペット同伴、車椅子・要介護など）
  - 支援物資ニーズ（飲料水・食料、毛布・防寒具、携帯トイレ、医療相談・常備薬、粉ミルク・紙おむつ、衛生用品、充電・ガソリン等）
- **デジタル会員証（避難受付証）の自動発行**:
  - 巨大な区画番号表示（No. 001〜150）
  - 避難者照合用QRコード描画（Canvasレンダリング）
  - 食事や物資受取時の提示機能 & 配布済み物資の受取履歴表示
  - 体調の再申告（体調悪化時の即時更新・救護班自動連携）ボタン
  - 印刷・画面保存機能
- **受付証（会員証）の再表示・再発行機能**:
  - ブラウザやタブを閉じた場合でも、登録した**電話番号・氏名・ナンバー**の入力で受付証を瞬時に復元・再表示。
  - LocalStorageによる直近受付証の自動保持機能。

---

### 2. 行政・避難所スタッフ向け機能（セキュリティログイン保護）
- **セキュリティ機能（スタッフ認証ログイン）**:
  - 行政管理者・現地避難所スタッフ・DMAT医療班別のロール管理
  - 演習・審査・防災訓練用のワンクリックプリセットアカウントを搭載
- **健康リスク警戒 & 統合ダッシュボード**:
  - 熊本地震の教訓に基づいた「エコノミークラス症候群・健康悪化緊急警戒アラート」
  - リアルタイムKPI統計（総避難者数、駐車台数、収容率、24h超滞在者数、体調不良者数、要配慮者数）
  - 自動リスク判定ロジック（体調不良、足のむくみ・息苦しさ、滞在時間24h超、特記事項からCRITICAL / HIGH / MEDIUM / LOWを自動算出）
  - 要即時確認・見回りリスト & ワンクリック見回り完了機能
  - 支援物資ニーズのリアルタイム需要集計（同乗者換算の必要人分・割合）
- **パーキングマップ機能**:
  - **アクアドームくまもと（150台）** & **熊本競輪場（150台）** の駐車区画をリアルタイムで色分け描画
  - リアルタイム色分け管理：
    - 🟢 **空き区画**（新規受け入れ可能）
    - 🔵 **駐車中・安定**（体調良好・一般）
    - 🟡 **要配慮・注意**（妊産婦、乳幼児、高齢者、滞在24h超など）
    - 🔴 **体調不良・要警戒**（足のむくみ、呼吸困難、発熱など）
  - 区画クリックによる避難者カルテ詳細表示 & クイック巡回記録
  - 空き区画クリックによる代理受付機能
  - 全ブロック一括表示およびステータス絞り込み・リアルタイム検索
- **避難者台帳・データ管理**:
  - 多次元リアルタイム検索（氏名、電話番号、車番、区画番号、ID）
  - 複合条件絞り込み（施設、体調、リスク、滞在時間、巡回状況）
  - 詳細情報の編集モーダル（全項目更新可能）
  - 退去（チェックアウト）時のデータ削除
- **物資配布照合端末（QRスキャナー・手動照合）**:
  - 避難者の受付証QRコードやID、区画番号から即時照合
  - 物資（食料・水・毛布・オムツ等）の配布完了ログを記録
- **インポート・エクスポート機能**:
  - **UTF-8 BOM付きCSVエクスポート**: Microsoft Excelで直接ダブルクリックしても文字化けしない完全仕様
  - **CSVインポート**: 外部台帳や他避難所名簿の一括取り込み
  - **取込用ひな形（テンプレート）CSVダウンロード**
  - **JSON完全バックアップ & 復元（リストア）**
  - **初期デモデータへのリセット機能**（リアルな避難者サンプル約105台分を即座に再投入可能）

## 🚀 起動方法

### 開発用ローカルサーバーの起動
```bash
npm run dev
```
ブラウザで `http://localhost:3000` にアクセスしてください。

### プロダクションビルド
```bash
npm run build
npm run preview
```
